# 👛 Pocket Planner Pro

> **Smart financial tracking made simple, secure, and fully customizable.**

Pocket Planner Pro is a feature-rich, single-page personal finance web application designed to help you manage your wealth, monitor daily spending, track investments, and plan for your financial future—all with a sleek, responsive UI and complete local data privacy.

## ✨ Key Features

* **Secure Authentication**: Local username and 4-digit PIN protection keeping your financial data private.
* **Comprehensive Dashboard**: Real-time overview of total balance, income, expenses, and quick budget tracking.
* **Transaction Management**: Easily add, edit, categorize, and search income and expense records with custom date selection[cite: 2].
* **Interactive Calendar View**: Visual day-by-day breakdown of cash flows, recurring expenses, and active goals[cite: 2].
* **Advanced Analytics**: Clean data visualisations powered by **Chart.js** to monitor spending patterns[cite: 2].
* **Investment Portfolio**: Track stocks, crypto, bonds, real estate, and mutual funds with profit/loss metrics[cite: 2].
* **Savings Goals**: Set target amounts, track progress visually, and contribute funds dynamically[cite: 2].
* **Subscriptions & Monthly EMIs**: Keep tabs on recurring bills, streaming services, and active loan schedules[cite: 2].
* **Bank Accounts**: Manage multiple bank accounts, checking/savings balances, and account-specific ledgers[cite: 2].
* **Customization & Themes**: 
  * Light, Dark, and System theme synchronization[cite: 2].
  * Fully customizable background gradients, color schemes, card tones, and navigation accents[cite: 2].
  * Preset quick themes (Cosmic, Sunset, Ocean, Forest, Cyberpunk, etc.)[cite: 2].
* **PDF Reporting**: Export clean summary PDF reports using **jsPDF**[cite: 2].
